# APK vía EAS Build — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar el repo listo para que `npx eas build --platform android --profile preview` produzca un APK instalable apuntando a la API LAN.

**Architecture:** Solo config: `app.json` (nombre visible, package Android, plugin `expo-build-properties` para cleartext HTTP) + `eas.json` nuevo (perfil `preview` → APK con la URL de API horneada). Una dependencia nueva alineada al SDK con `npx expo install`.

**Tech Stack:** Expo SDK 57, EAS Build (nube).

**Spec:** `docs/superpowers/specs/2026-08-11-apk-eas-design.md`

## Global Constraints

- URL exacta horneada: `http://10.134.78.227:8000/api/v1`.
- Package Android exacto: `com.cafeteriaaroma.app`.
- Idioma: comentarios y commits en español.
- No correr `eas login` ni `eas build` (interactivos, credenciales del usuario).

## File Structure

```
mobile/app.json        (edit)   name, android.package, plugin expo-build-properties
mobile/eas.json        (create) perfil preview → APK
mobile/package.json    (edit por npx expo install expo-build-properties)
mobile/package-lock.json (idem)
```

## Tarea 1 — Config de EAS y build properties

**Files:**
- Modify: `mobile/app.json`, `mobile/package.json` (+lock, vía CLI)
- Create: `mobile/eas.json`

- [ ] **Paso 1: dependencia**

```bash
cd /home/vikca/cafeteria-system/.claude/worktrees/eas-apk/mobile
npm install               # primera vez en el worktree
npx expo install expo-build-properties
```

- [ ] **Paso 2: `app.json`**

- `"name": "mobile"` → `"name": "Cafetería Aroma"` (solo `name`; `slug` queda `"mobile"`).
- En `"android"`, agregar como primera clave: `"package": "com.cafeteriaaroma.app",` (conservar `adaptiveIcon` y `predictiveBackGestureEnabled`).
- En `"plugins"`, después del bloque de `expo-splash-screen`, agregar:

```json
      [
        "expo-build-properties",
        {
          "android": {
            "usesCleartextTraffic": true
          }
        }
      ],
```

(La API LAN es `http://` sin TLS; los builds release de Android bloquean cleartext por defecto — sin esto el APK no conecta.)

- [ ] **Paso 3: `mobile/eas.json`** (archivo nuevo, contenido completo):

```json
{
  "cli": {
    "appVersionSource": "remote"
  },
  "build": {
    "preview": {
      "distribution": "internal",
      "android": {
        "buildType": "apk"
      },
      "env": {
        "EXPO_PUBLIC_API_BASE_URL": "http://10.134.78.227:8000/api/v1"
      }
    }
  }
}
```

- [ ] **Paso 4: Verificación**

```bash
npx expo config --type public > /dev/null && echo "CONFIG OK"
npm test && npx tsc --noEmit
```

Esperado: CONFIG OK, 113 tests verdes, tsc limpio.

- [ ] **Paso 5: Commit**

```bash
git add mobile/app.json mobile/eas.json mobile/package.json mobile/package-lock.json
git commit -m "feat(mobile): configuración de EAS Build para APK (perfil preview, API LAN)"
```
